# Product

India Weather App: a small static web app for a live workshop demo. The user types an Indian city and sees current weather: place name, temperature, feels-like, humidity, wind speed, precipitation, and a text description of the weather code.

- Must work on first run with no API keys, accounts, or server-side code.
- Error states: empty input, city not found in India, network/API failure. Loading state shown while fetching.
- Deployment (Netlify or AWS S3/CloudFront) comes later, only when the user asks.
